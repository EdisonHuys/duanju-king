## 一、 交付物范围总览 (Deliverables)

本项目完整交付包含以下 4 个部分：
1. **微信小程序客户端（`uni-app` 工程源码与编译包）**：支持单机离线游玩、4 部首发剧本、拍摄质量评分、杀青海报生成、全服/单剧排行榜、好友 PK 挑战、28 图鉴收集。
2. **服务端 API / 云函数工程**：负责微信静默登录、剧本热更下发、杀青分数防作弊复算、排行榜高频读写、微信官方内容安全（`msgSecCheck`）改名校验。
3. **运营管理后台（Admin CMS 网页端）**：负责剧本可视化增删改查及 JSON 导入导出、图鉴管理、用户与拍摄记录查询、排行榜风控下榜、选项点击率统计及广告/提审开关配置。
4. **配套静态资产**：4 部完整剧本数据（24 集 / 72 选项 / 16 结局 / 28 图鉴）、波普风 UI 组件库及搞笑音效包。

### 2.3 杀青结算、质量评分与排行榜攀比系统 (`pages/ending` & `pages/rank`)

| 需求编号 | 功能点 | 详细开发需求描述 | 验收标准 (Acceptance Criteria) |
| :--- | :--- | :--- | :--- |
| **F-MP-03.1** | **结局判定与拍摄质量分算法** | 1. 6 集结束后，按剧本 `endings` 数组中 `priority` 从高到低匹配结局条件（`specialChoice` / `minAbsurd` / `minThrill` / `default`）。<br>2. 计算综合拍摄质量分（$0 \sim 100$ 分，保留两位小数）：基础分 40 + 6集选项质量分均值换算 + 风格连击加成（连续4集高脑洞或高爽感额外 +6~8分）+ 结局稀有度加成 + 微小随机浮动（同路径多次刷可相差 $\pm 1.5$ 分以刺激刷极限高分）。<br>3. 根据质量分换算评级印章（`UR/SSR/SR/R`）、模拟首日播放量（50万 ~ 9.9亿）及击败全国导演百分比。 | **AC-03.1**：<br>- 任意选项组合 100% 必命中一个有效结局，绝不出现空结局报错。<br>- 乱选平庸路线得分落在 `68.00 ~ 82.00` 之间；走极致路线并命中 SSR/UR 结局得分落在 `92.00 ~ 99.80` 之间，梯度区分明显。 |
| **F-MP-03.2** | **杀青报告 UI 与战绩自动冲榜** | 1. 参照原版结算封面布局：顶部「杀青大吉」顶标、结局插画、大字号拍摄质量评分与彩色进度条、结局称号、剧情总结、网友神评。<br>2. 页面加载时自动将 `{ scriptId, actorName, choicePath, qualityScore, boxOffice, endingId }` 上报服务端排行榜。<br>3. 若打破个人在该剧本的历史最高分，弹出「🏆 刷新个人最佳导演纪录！当前位列全服第 X 名」动效。 | **AC-03.2**：<br>- 联网状态下 1 秒内完成战绩上报并返回最新全服排名。<br>- 弱网/断网状态下先将战绩存入本地 `pendingUploads` 队列，网络恢复或下次打开小程序时自动静默补传。 |
| **F-MP-03.3** | **Canvas 杀青海报与好友 PK 裂变** | 1. 点击「生成杀青海报」：使用 Canvas 离线绘制高清波普风长图（含剧本名、主演署名、质量评分大字、模拟播放量、结局称号、网友热评、小程序码），支持一键保存到手机相册。<br>2. 点击「发群里比比谁分高」：触发微信转发卡片，携带参数 `?challenger=昵称&score=96.85&scriptId=xxx`。<br>3. 被分享好友点击进入小程序时，首页与拍摄页顶部显示挑战条：`🔥 正在挑战 [XXX] 的 96.85 分纪录`；好友杀青时弹出双方分数对比盖章（`挑战成功` / `惜败`）。 | **AC-03.3**：<br>- 真机生成海报耗时 < 1.5s，无跨域图片空白、无文字截断。<br>- 用户拒绝相册权限时，自动弹窗引导打开 `uni.openSetting`。<br>- 从分享卡片进入的挑战流程参数解析 100% 准确。 |
| **F-MP-03.4** | **多维封神排行榜 (`pages/rank`)** | 1. 支持顶部 Tab 切换：**「单剧最高分榜」**（二级胶囊切换 4 部剧本）与 **「全服百亿导演总榜」**（按4部剧本最高播放量总和 + 图鉴收集率）。<br>2. 榜单列表展示：名次（Top 3 专属金银铜皇冠）、导演头像与昵称、`主演：[自定义名]`、结局标签、质量分（或总播放量）。<br>3. 底部悬浮固定栏始终显示当前玩家自己的排名与分数。 | **AC-03.4**：<br>- 同一玩家在同一剧本下仅展示其历史最高分的一条记录，不重复占榜。<br>- 列表支持下拉刷新，前 100 名加载响应时间 < 500ms。 |

## 四、 非功能性需求与微信小程序上架合规标准 (NFR)

1. **性能与包体标准（NFR-01）**：
   * 微信小程序主包体积 $\le 1.8\text{ MB}$（音频与大图采用分包或 CDN 按需加载）。
   * 首页冷启动首屏可交互时间（TTI）$\le 1.2\text{ 秒}$；选项点击到点评弹窗弹出延迟 $< 100\text{ ms}$。
2. **离线高可用标准（NFR-02）**：
   * 小程序内置最新一份 `SCRIPTS_DATABASE.json` 作为兜底数据。在手机开启飞行模式或云端服务超时（$>2.5\text{ 秒}$）时，自动无缝降级为本地剧本数据，保证单机游玩、算分、本地图鉴收集 100% 不受影响。
3. **跨设备适配标准（NFR-03）**：
   * 完美适配 iPhone SE（小屏）、iPhone 15/16 Pro Max（灵动岛+底部黑条）、主流安卓全面屏（华为/小米/OPPO）及微信 PC/Mac 桌面端小程序窗口。
4. **微信小程序过审合规标准（NFR-04）**：
   * **类目合规**：工程配置为标准微信小程序（非小游戏 `game.json`），提审类目为 `文娱-其他视频` 或 `工具-娱乐`，免游戏版号。
   * **隐私合规**：严格按微信最新规范配置《用户隐私保护指引》（仅在用户主动上传自定义头像昵称或保存海报到相册时触发授权申请，不强制弹窗拦截首屏体验）。

## 五、 最终交付测试验收清单 (QA Sign-off Checklist)
